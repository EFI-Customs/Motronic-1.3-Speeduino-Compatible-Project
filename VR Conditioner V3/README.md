This is a design based on the Speeduino V3 VR Conditioner that you can find [here](https://github.com/speeduino/Hardware/tree/main/VR%20Conditioner/Prior%20Versions/v3)

It is electronically identical but has been converted to a KiCAD project and uses smaller footprints for the additional resistors and a revised circuit board package size.

I have provided the KiCAD project files in the KiCAD directory. The Gerber, BOM and Positions files are available so that you may easily order from JLCPCB. Note that the jumper, 2 resistors and empty 8 pin DIP socket will come back as unpopulated when requesting PCB assembly.
